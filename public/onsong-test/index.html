2. Import a combined ChordPro file

The sample file holds two made-up songs separated by {new_song}: JED Test Alpha (key D) and JED Test: Beta's Song (Café) (key C). Try each way of getting it into OnSong. Delete the songs from OnSong between tries, or keep them to see the duplicate prompt.

2c. onsong://ImportData link 2d. onsong:// file URL
  • 2a opens the iPad Share sheet. Is OnSong listed? Do both songs import separately?
  • 2b saves the file to Downloads. Then open it in OnSong from Files or the Downloads list.
  • 2c puts the whole file inside the link as Base64. No download step, if it works.
  • 2d lets OnSong fetch the file from this site. The docs say OnSong tries http:// first and follows a redirect to https://.
